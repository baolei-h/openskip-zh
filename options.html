在坚果云网页版 → 账户信息 → 安全选项 → 第三方应用管理 → 添加应用，生成一个应用密码（不是登录密码）。只需要填下面三项，不用注册别的服务，也不用跑 SQL。

OpenSubtitles 可选

自动获取字幕 — 可选，可提升配额

无账号每天可下载 5 次。使用 免费账号：每天 20 次。VIP 账号更多。登录后本页会显示 OpenSubtitles 返回的次数。字幕语言请在弹窗中设置。Video Sync 会先以无账号方式下载，因此只有 5 次用完后才会动用你账号的 20 次。

Supabase 可选

可选云同步 — 使用你自己的私有项目

Supabase 控制台 → Project Settings → API → Project URL。

Project Settings → API Keys。请使用 publishable key（以 sb_publishable_ 开头）。旧版 anon key（以 eyJ 开头）同样可用。切勿使用 secret key。Video Sync 不会在你的项目里执行 SQL，安装脚本需要你自己运行一次（本页有说明）。

只差一步，仅需一次。 Video Sync 无法在你的项目里创建数据表：你的 anon key 没有这个权限，这也保证了项目安全。请自己运行安装脚本：

  1. 点击 打开 SQL 编辑器。Supabase 会带着脚本打开；如提示登录，请先登录。
  2. 在 Supabase 中点击 运行。
  3. 回到本页点击 再次检查。
打开 SQL 编辑器

脚本会新增两张表（playback_states 与 user_settings）以及 Video Sync 调用的函数，不会改动其他内容，重复运行也安全。如果你的项目中已有同名的其他用途数据表，请换一个新项目。

备份与恢复

一个文件即可在另一台浏览器或重装后恢复全部内容。
  1. 保存： 选择要包含的内容；如果包含密钥，请输入口令；然后点击「导出全部」。
  2. 恢复： 在另一台浏览器输入相同口令，点击「导入备份」，选择文件。
  3. 页面会自动刷新，内容全部恢复。两台浏览器上的数据都不会被删除。

数据来源

跳过时间、海报与字幕的来源
  • IntroDB
    按 IMDb id 提供剧集与电影的片头、回顾和片尾时间。无需账号，密钥仅用于提交时间点。
  • TheIntroDB
    按 TMDB 或 IMDb id 提供片头、回顾、片尾与预告时间。无需账号，密钥仅用于提交时间点。
  • SkipDB · 数据 ODbL 1.0
    按 IMDb id 提供片头、回顾、片尾与预告时间。无需账号。
  • SponsorBlock · 数据 CC BY-NC-SA 4.0
    YouTube 的赞助片段、提醒、片头与精彩片段。无需账号。
  • AniSkip
    按 MyAnimeList id 提供番剧片头、片尾与回顾。无需账号。
  • Jikan
    为番剧标题查询 MyAnimeList id（供 AniSkip 使用）。无需账号。
  • Anime Skip
    更多番剧时间点。可选：免费 Client ID（账号页）。
  • TMDB
    海报、片名与 id。本产品使用 TMDB 及 TMDB API，但未获得 TMDB 的认可、认证或其他形式的批准。可选：你自己的免费密钥（账号页）。
  • OpenSubtitles
    字幕。可选：无账号每天 5 次下载，免费账号每天 20 次。
  • Supabase
    在你自己的项目里做云同步。可选：自建项目（账号页）。

图标是各来源自己的站点图标，仅在打开「账号」或「数据来源」时从对应网站加载（失败时改用 DuckDuckGo 的图标服务）。它们归各自所有者所有，仅用于标示数据来源。
